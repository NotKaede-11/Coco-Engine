A little about Coco.

Coco Chess Engine is an open-source C++20 UCI engine maintained by NotKaede-11. It combines NNUE evaluation with multithreaded search and optional Syzygy tablebases.

Named after Coco from Witch Hat Atelier, and built with the same spirit of curiosity. Coco Chess Engine and CuckooChess are different projects.
