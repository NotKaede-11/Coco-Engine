Coco Chess Engine is a C++20 project maintained by NotKaede-11. Behind the pointed hat is an alpha-beta search, a compact neural evaluator, and a shared ambition: keep finding better moves.

The name comes from Coco in Witch Hat Atelier. Her curiosity gives the project its name and this page its atmosphere. The engine is its own open-source project.

A network in every download.

A 512-unit NNUE evaluates positions with incremental updates as pieces move. The network is embedded in release binaries, so there is no separate model to find.

Every move, earned.

Staged move ordering, principal-variation search, guarded pruning, and a transposition table guide the calculation. Coco has no built-in opening book.

At home in your chess GUI.

UCI support, MultiPV analysis, Lazy SMP multithreading, and optional Syzygy probing. Choose a release for your platform and connect it to your favorite interface.

What is Coco Chess Engine?

Coco is a free, open-source C++20 chess engine maintained by NotKaede-11. It speaks the Universal Chess Interface (UCI) protocol and uses NNUE evaluation with Lazy SMP parallel search. Its source and releases are hosted at NotKaede-11/Coco-Engine.

Is Coco the same as CuckooChess?

No. Coco Chess Engine and CuckooChess are different projects. This page is for Coco, the C++20 NNUE engine maintained at NotKaede-11/Coco-Engine.

Do I need to download a neural network?

No. Published Coco binaries include the network. Advanced users can load a compatible external network through the EvalFile option; arbitrary NNUE files from other engines are not interchangeable.

Can I play chess on this website?

This is Coco’s project and download page. To play against the engine, install it in a UCI-compatible chess GUI. You can also visit the Coco_Engine profile on Lichess.

How strong is Coco?

Coco 1.5.0 has an approximate 2,977 Elo estimate from a filtered local gauntlet calibration. It is not an official CCRL rating, and performance depends on hardware, time control, and opponents. Read the full results and methodology for context.

Is this an official Witch Hat Atelier project?

No. Coco Chess Engine is an unaffiliated open-source chess project. Its name and visual inspiration come from Coco in Witch Hat Atelier by Kamome Shirahama.
